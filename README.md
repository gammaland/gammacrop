# GammaCrop

Free, private, browser-based image prep for UV-printed fridge magnets (built for the EufyMake E1).

**Live:** https://tool.gammaland3d.com/

EufyMake Studio only crops to sharp rectangles, but magnet blanks have rounded corners. GammaCrop crops to the exact magnet size with matching rounded corners, optionally removes the background with a local AI model, and exports a PNG with embedded DPI so Studio imports it at the correct physical size.

## Features

- Rounded-corner cropping for 50×70, 70×50, 57×57 mm or any custom size
- Local AI background removal: Fast (MODNet) or HD (IS-Net), WebGPU with WebAssembly fallback
- Edge refinement (threshold / feather / erode), auto hole-fill, manual eraser
- Safety margin: 0 by default; negative values add bleed for edge-to-edge prints with an overspray mask
- Export at 300 / 600 / 720 / 1440 DPI with `pHYs` metadata
- Presets with shareable URLs, live export preview, zoom / pan / nudge controls
- Nothing is uploaded: all processing runs in the browser; settings live in `localStorage`

## Run locally

It is a single static page with no build step or dependencies to install:

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

The AI models and Transformers.js load from public CDNs on first use, so the first background removal needs a network connection.

## Project layout

| Path | What it is |
|------|------------|
| `index.html` | The whole app (HTML + CSS + JS) |
| `CHANGELOG.md` | Release notes, newest first |
| `llms.txt`, `robots.txt`, `sitemap.xml` | SEO / crawler files |
| `404.html` | Not-found page (also makes Cloudflare Pages return real 404s) |
| `blog/` | Redirect to the dev blog |
| `blog-pic/` | Screenshots referenced from the changelog |
| `deploy.sh` | Rebuilds `deploy/` (the publish directory) from the source files |
| `deploy/` | Build output (git-ignored); generated by `deploy.sh` |

## Deploying

Cloudflare Pages builds `main` with build command `./deploy.sh` and output directory `deploy`. Run `./deploy.sh` locally to preview the exact publish set.
